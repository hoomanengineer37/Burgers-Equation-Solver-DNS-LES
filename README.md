Graph A compares the velocity profiles from DNS (circles) and LES (squares) at t = 0, 0.3, 0.5 and 1.0 on the same 1601-point grid. The two solutions agree very closely throughout the run: the relative difference stays below 0.15%, and the LES markers lie on the DNS markers everywhere except a few grid cells next to the wall at x = 1, where the front is steepest. There, the Smagorinsky model adds a small eddy viscosity, at most about 10% of the molecular viscosity, which slightly smooths the gradient without changing the overall solution. This is the expected behaviour of a correctly implemented subgrid-scale model: it acts only where gradients are steep and reduces to the DNS solution when the grid resolves the flow. The results therefore validate that the LES implementation matches DNS at high grid resolution.

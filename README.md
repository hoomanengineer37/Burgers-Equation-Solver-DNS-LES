This project is a C++ numerical model developed to show the performance of the Direct Numerical Simulation (DNS) and Large Eddy Simulation (LES) approaches for one-dimensional flows. It solves the viscous Burgers’ equation, a widely used 1D model problem for turbulence that captures the competition between nonlinear convection and viscous diffusion and the formation of steep fronts. The equation is discretized with second-order central finite differences in space and explicit time integration with adaptive, stability-limited time steps. The solver can run either as a fully resolved DNS or as an LES with a Smagorinsky subgrid-scale model, and a filtered DNS solution is produced for direct comparison with LES. Because the diffusion coefficient can be varied, the model covers both laminar and turbulent-like regimes. On a fine grid, the LES results agree closely with DNS, which validates the implementation of the subgrid-scale model. This work is part of my broader research on the numerical study of turbulent flows.
Graph A compares the velocity profiles from DNS (circles) and LES (squares) at t = 0, 0.3, 0.5 and 1.0 on the same 1601-point grid. The two solutions agree very closely throughout the run: the relative difference stays below 0.15%, and the LES markers lie on the DNS markers everywhere except a few grid cells next to the wall at x = 1, where the front is steepest. There, the Smagorinsky model adds a small eddy viscosity, at most about 10% of the molecular viscosity, which slightly smooths the gradient without changing the overall solution. This is the expected behaviour of a correctly implemented subgrid-scale model: it acts only where gradients are steep and reduces to the DNS solution when the grid resolves the flow. The results therefore validate that the LES implementation matches DNS at high grid resolution.
